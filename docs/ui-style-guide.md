# Language Annotator UI Style Guide

## A Takahata-Inspired Everyday Design

The interface of Language Annotator should not feel like a software system.
It should feel more like a learning notebook that someone uses regularly on their desk.

This product exists inside someone's daily life.
It should carry:

- the scent of book pages
- the light of a desk
- traces of use
- the quiet passage of time

The interface is not meant to showcase technology; it is meant to accompany learning.

## Core Character

The product should feel:

- warm rather than technological
- used rather than freshly manufactured
- like a book rather than a system
- like daily life rather than a tool

Opening this product should feel like:

opening your own notebook.

## Worldview: A Desk, Not a System

The entire interface should feel like reading and studying at a desk.

Visual elements should resemble:

- book pages
- sticky notes
- bookmarks
- handwritten marks
- folded page corners
- layers of paper

Not:

- panels
- control consoles
- dashboards

The product is not a management tool, but a learning space.

## Material Language

The interface should evoke materials from everyday life.

The most important material is paper.

Paper is not only a color, but a feeling.

Background surfaces should resemble:

- book pages
- notebook paper
- letter paper
- the inner pages of an old book

Colors should carry warmth.

Paper tones:

- `#fffaf3`
- `#f6efe6`
- `#eee5d8`

Text should feel like ink rather than screen pixels.

Ink tones:

- `#34251f`
- `#4e3e36`

Supporting text should resemble lighter ink.

- `#7b655b`
- `#8a7769`

Accent colors should resemble terracotta or old book covers.

- `#a55143`
- `#8f5143`
- `#8e4337`

Avoid:

- cold technological blues
- fluorescent colors
- pure black
- futuristic gradients

## Imperfect Geometry

Real paper is never perfectly straight.

Interface shapes do not need to be overly precise.

Card corners may vary slightly.
Shadows can remain soft.
Edges may be slightly asymmetrical.

This is not random design; it imitates objects that have been handled by people.

Avoid:

- perfectly rigid grid geometry
- sharp rectangles
- high-contrast borders

## Typography

The layout should resemble a book page.

Reading is the most important activity in this product.

Recommended heading fonts:

- `Noto Serif TC`
- `Hiragino Mincho`
- `Yu Mincho`

Body text:

- `Noto Sans TC`
- `Hiragino Sans`
- `Yu Gothic`

Headings should resemble chapter titles in a book.

Body text must remain comfortable to read.

Line height should be generous.
Paragraphs should have breathing room.

The interface should never feel like a spreadsheet.

## Traces of Use

One of the most important qualities in Takahata's works is the sense of time.

The interface should feel as though it has been used.

For example:

- studied words appear marked
- newly added words feel like they were just written into a notebook
- repeatedly reviewed words accumulate more notes

These traces should not be exaggerated.

They should exist quietly.

## Highlighting

Word highlighting should resemble marks made by someone studying in a book.

The color should resemble a gentle yellow note highlight.

- `#efe0a8`

Highlights should not appear as rigid rectangles.

They should feel like:

- lightly brushed markings
- soft rounded emphasis

Avoid fluorescent marker effects.

## Cards

Cards should resemble sheets of paper placed on a desk.

However, avoid stacking many boxes inside boxes.

The layout should resemble a book page:

- one primary surface
- content separated by spacing

Instead of:

- border
- border
- border again

Separation should rely on:

- whitespace
- subtle tonal surfaces
- dashed dividers

## Buttons

Buttons should feel like small tactile objects.

Primary buttons may use terracotta tones.

Secondary buttons may resemble paper labels or tags.

Hover behavior should only include:

- a slight lift
- a gentle shadow

Avoid:

- glossy effects
- exaggerated animations
- black buttons

## Preview Cards

Word hover previews should resemble small note cards.

Content hierarchy:

- The word (clear heading)
- Short example sentences
- Translation as supporting information

The result should resemble a small dictionary entry.

Avoid stacking many mini-components.

## Motion

Motion should resemble breathing.

Typical motion:

- fade in
- gentle upward rise
- soft shadow change

Animations should be short, quiet, and natural.

Avoid:

- shaking
- flashing
- arcade-style effects

## Practice Mode

Practice mode can be more lively.

When the user answers correctly, the interface may show:

- paper fragments
- glowing particles
- celebration effects

However, the same color language must remain.

It should not become a neon game interface.

## Page Atmosphere

### Popup

The popup should resemble a study card.

Opening it should feel like:

"I'll take a quick look at this word."

Simple, warm, and clear.

### Words Page

The Words page should resemble a vocabulary notebook.

It should have:

- chapter-like structure
- reading rhythm
- quiet order

It should not feel like a data management interface.

### Options Page

The settings page should resemble a chapter in a handbook.

Each setting should feel like a short explanation.

Avoid making the page look like a system control console.

## Design Principles

When designing a new interface, ask:

Does this feel like part of everyday life,
or like a piece of software?

Does it resemble a book page,
or a control panel?

Is the interface quiet,
or too loud?

If a screen looks too much like a product design mockup,
it has probably drifted away from the intended direction.

## The Most Important Sentence

The interface of Language Annotator should not resemble a technology product.

It should resemble:

a language notebook slowly written on a desk.

If opening the product feels like flipping through one's own study notes,

then the design has succeeded.
